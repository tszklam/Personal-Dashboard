Privacy policy

tkopc dashboard is a personal tool used only by its owner, on the owner's own computer.

What it accesses

With the owner's consent it reads the owner's Gmail messages, Google Calendar events and calendar list, and Google Tasks, and can create Gmail drafts, send email, and create or change calendar events and tasks when the owner confirms each action.

Where the data goes

Data is processed on the owner's computer, including by a language model running locally on that computer. It is not sold, shared, transferred to third parties, or used for advertising or for training models. OAuth tokens are stored only on that computer.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
